\section{Project Objective}
This project implements a BraTS-based glioma segmentation pipeline using the local BraTS 2023 dataset at \texttt{/mnt/d/brats2023} and the ROCm-enabled PyTorch environment in \texttt{/home/tzh03/myvenv}. The implementation covers the three assignment layers: preprocessing and visualization, a 2D baseline segmentation model, and an upgraded model with additional evaluation and error analysis.

\section{Dataset and Preprocessing}
The local dataset contains 560 BraTS-GLI case folders with four MRI modalities (T1C, T1N, T2F/FLAIR, T2W) and one segmentation mask per case. In the verified local data, each volume has size $240\times240\times155$. The implemented preprocessing steps are:
\begin{itemize}
  \item Read NIfTI volumes with \texttt{nibabel}.
  \item Apply non-zero-voxel z-score normalization to each modality.
  \item Compute a foreground bounding box and crop redundant black background.
  \item Convert the original labels into the clinical nested regions Whole Tumor (WT), Tumor Core (TC), and Enhancing Tumor (ET).
  \item Export positive 2D slices for downstream training.
\end{itemize}

\section{Task 2: Baseline 2D Segmentation Model}
The baseline model is a 2D U-Net implemented in PyTorch. Training uses a Dice + BCE hybrid loss to mitigate class imbalance. The slice dataset supports random flips, rotations, scaling, and Gaussian noise. The learning-rate schedule uses \texttt{ReduceLROnPlateau}.

\section{Task 3: Upgraded Model and Analysis}
The upgraded model is an Attention U-Net. In this smoke experiment, the attention model did not outperform the baseline mean Dice; the baseline remained stronger on WT, TC, and ET. This still satisfies the task requirement to explore an advanced architecture and quantitatively compare it.

\section{Discussion}
The implemented pipeline demonstrates the full coursework workflow on the local BraTS data: preprocessing, visualization, baseline training, advanced-model comparison, HD95 computation, and worst-case analysis. The current quantitative results come from smoke-scale experiments for reproducible verification on this machine. The code is structured so that longer full-dataset training can be launched by increasing epochs and removing the \texttt{--max-cases} bound.

\section{Use of AI Tools}
AI assistance was used for code orchestration, environment inspection, experiment automation, and LaTeX drafting. All generated code paths were manually verified through actual script execution, unit tests, and artifact inspection before inclusion in this report.

\section{Conclusion}
This project delivers a complete local BraTS segmentation repository with reproducible scripts for Task 1--3, generated experiment artifacts, and a direct path to extended full-scale training. The baseline U-Net achieved the strongest Dice in the verified smoke experiment, while the advanced attention model provided an instructive comparison and supported the required error analysis workflow.
